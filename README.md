# 赛程 · 每日足球

每天打开看一眼赛程的小页面：无广告、无推荐、无新闻，只有比赛。
双击 `index.html` 即可使用，不需要安装任何东西，不需要服务器。

## 使用

- 双击 `index.html`（默认浏览器打开即可，Chrome / Edge 都行）。
- 球队名旁的 ☆ 点一下即关注（★）。关注的球队当天的比赛会置顶到"★ 我的关注"（带联赛标签），
  日期条实心点=当天有关注球队的比赛、空心点=只有其他比赛；没比赛的日子，"最近的比赛"也优先跳关注球队。
- 顶部日期条切换日期，也支持键盘 ← → 翻日；日期条上的小圆点表示那天有比赛。
- 当天（或选中的日子）没比赛时，不用干瞪眼：页面直接给出**最近的比赛**预览，
  以及"上一个/下一个比赛日"一键跳转。
- 联赛圆点可开关（英超/西甲/德甲/意甲/法甲/欧冠/欧联/中超/英冠/日职/欧协联），选择会记住。
- 比赛时间为本机时区；有比赛正在进行时每分钟自动刷新比分。
- 赛程按月拉取并缓存在浏览器本地：看过的日期再次打开秒出，断网也能看缓存。

## 数据源：一般怎么解决

这类需求（个人用、只看赛程）常见的三种方案：

1. **免费公开接口（本项目采用）**
   ESPN 站内公开 JSON（`site.api.espn.com`）：免注册、免密钥、CORS 全开，
   覆盖五大联赛、欧冠/欧联/欧协联、英冠、中超、日职等，含未来赛程与比分。
   缺点：非官方公开承诺的接口，字段可能变动——所以数据层全部收敛在 `data.js` 一个文件里，
   真变了只需要改 `fetchBucket` / `normalizeEvent`。
   （TheSportsDB 也是免密钥接口，但免费档对返回条数有硬限制，实测一天只剩 3 条，不适合赛程场景。）

2. **官方免费套餐 + 本地小代理**
   - football-data.org：免费档 12 项赛事（五大联赛、欧冠、英冠、巴甲等），10 次/分钟，赛程/积分榜免费，实时比分要付费（€12/月）。
   - API-Football：免费档 100 次/天、10 次/分钟，数据更细，但轮询实时比分很快会烧穿额度。
   这类接口要么要密钥、要么 CORS 受限，标准做法是加一个很小的本地服务端做两件事：**藏密钥 + 按天缓存**，
   浏览器只访问本地。个人用几百行 Python（FastAPI/甚至标准库）就够。

3. **付费数据商**（Opta / StatsBomb / Sportradar 等）：做正式产品才需要，按年按赛事报价。

另外不建议直接爬国内体育站（懂球帝/直播吧等）：页面结构说变就变，还有合规风险。

通用经验：不管用哪个源，都值得做一层**按天缓存**（本项目存 localStorage，服务端方案存 SQLite/文件），
这样每天打开是秒开的，源站抽风或断网时也能看最近一次的数据；时区一定要在客户端按本地日期切分，
本项目中华东时区的早场（如凌晨 3:00）会正确归到当天。
图片同理：队徽显示只有 28px，走 ESPN 的缩略图接口（64px，约 6KB，缓存 24h），
而不是 500px 原图（约 130KB，缓存仅 2h）——一天 40 个队徽的场景下数据量差 20 倍。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架，双击入口 |
| `styles.css` | 样式（深色记分牌风格） |
| `config.js` | 联赛列表、默认开启项 |
| `team-names.js` | 球队中文名对照表（含队名归一化） |
| `tools/zh-coverage.html` | 队名覆盖检查：列出未收录中文名的球队 |
| `data.js` | 数据层：ESPN 抓取、归一化、按月缓存、时区分桶、空日就近搜索 |
| `app.js` | 界面层：日期/联赛切换、渲染、直播自动刷新 |

## 常见改动

- **加/减联赛**：`config.js` 里 `LEAGUES` 增删一行（`id` 为 ESPN 联赛标识，如 `por.1` 葡超、`ned.1` 荷甲）。
- **球队中文名**：`team-names.js` 增加一行；大小写、音调、`FC`/`AS` 前缀后缀等写法差异会自动归一，
  不用为同一支球队写多条。查漏有两个途径：双击 `tools/zh-coverage.html`，一次列出所有联赛里还没收录的队名
  （附可直接粘贴的空条目）；或平时看球时留意浏览器 console 的“未收录中文名”提示。
- **换数据源**：只需重写 `data.js` 的 `fetchBucket`（拉原始数据）与 `normalizeEvent`（归一化为
  `{id, league, start, status, minute, home, away}`），界面层不用动。
